# AI Resume Analyzer

AI-powered Resume Analyzer that evaluates resumes against job descriptions and generates ATS-based recommendations.

---

## Features

- ATS Score Generation
- Resume Parsing
- Job Description Matching
- AI Suggestions
- Resume Evaluation
